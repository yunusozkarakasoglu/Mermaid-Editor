1. Akış Şeması (Flowchart)

TD = yukarıdan aşağı, LR = soldan sağa. Düğüm şekilleri: [ ] dikdörtgen, { } karar, ( ) yuvarlak, (( )) daire. Kenarlar: --> ok, --- çizgi, -.→ kesikli, ==> kalın. Kenar etiketi: -->|metin|

flowchart TD
  A[Başla] --> B{Karar}
  B -->|Evet| C[İşlem]
  B -->|Hayır| D[Bitir]

2. Sıralama Diyagramı (Sequence)

->> düz mesaj, -->> kesikli yanıt, Note over ile açıklama.

sequenceDiagram
  participant K as Kullanıcı
  participant S as Sunucu
  K->>S: Giriş isteği
  S-->>K: Token döner

3. Sınıf Diyagramı (Class)

Kalıtım: <|--, uygulama: ..|>, ilişki: --, kompozisyon: *--

classDiagram
  class Hayvan {
    +String ad
    +sesCikar()
  }
  class Kedi
  Hayvan <|-- Kedi

4. Durum Diyagramı (State)

stateDiagram-v2
  [*] --> Boşta
  Boşta --> Çalışıyor: başlat
  Çalışıyor --> [*]: dur

5. Varlık İlişki Diyagramı (ER)

Kardinalite: ||--o{ (bir-çok), ||--|| (bir-bir), }o--o{ (çok-çok)

erDiagram
  KULLANICI ||--o{ SIPARIS : "verir"
  SIPARIS ||--|{ KALEM : "içerir"

6. Gantt (Zaman Çizelgesi)

gantt

  section Tasarım
    Arayüz: 2026-01-01, 7d

    API: 2026-01-08, 14d
